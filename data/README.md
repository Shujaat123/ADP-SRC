`positive_negative_cdhit50.fasta` and `.clstr` contain the corresponding CD-HIT50 input and cluster assignments used only for the secondary homology-aware grouped analysis.

The control class is not a collection of peptides experimentally shown to be inactive in all antidiabetic assays. Preserve this distinction when interpreting or reusing the data.
